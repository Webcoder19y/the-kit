About The Kit

The Kit is a small, growing collection of free browser tools — a word counter, a QR code generator, a password generator, a case converter, and more to come.

Every tool runs entirely in your browser using JavaScript. Nothing you type, paste, or generate is uploaded to a server or stored anywhere. Close the tab, and it's gone.

The site is built and maintained by one person, adding a new tool whenever there's time for it. If there's a tool you wish existed, get in touch.
